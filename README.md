# Paso Claro

Prototipo académico accesible creado para el Hackatón de Nuevas Tecnologías.

Paso Claro orienta a personas mayores para comprender los requisitos e iniciar la consulta de la Constancia de Vigencia de Derechos del IMSS mediante:

- lenguaje claro;
- navegación paso a paso;
- tipografía ajustable;
- alto contraste;
- lectura en voz alta;
- avisos de seguridad y privacidad.

> Este proyecto es una demostración académica. No pertenece al IMSS, no realiza trámites oficiales y no solicita ni almacena datos personales.
